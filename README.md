# Exp - 4 HOSPITAL MANAGEMENT SYSTEM

# AIM:
To study the problem statement, SRS document and draw all the UML diagrams of HOSPITAL MANAGEMENT SYSTEM.
# SRS (Procedure):
Step 1: Problem Identification The main problem is the need for a fast, secure, and automated system that allows patients to register, book appointments, consult doctors, manage medical records, and handle billing efficiently.

Step 2: Requirement Analysis Identify user needs: Patient,Doctor,Receptionist,Administrator Define functional requirements: Patient registration Doctor availability check Appointment booking and cancellation Patient record management Prescription management Billing and payment management Define non-functional requirements:Speed,Security,Reliability,Usability,Data integrity

Step 3: System Design Draw UML diagrams to represent the Hospital Management System: Use Case Diagram Class Diagram Activity Diagram Sequence Diagram Communication Diagram Package Diagram Design the database with tables for:Patient,Doctor,Receptionist,Administrator,Appointment,Medical Record,Prescription,Billing
